## 三、失败原因与报错信息

### 3.1 失败环节

在调用 B站评论接口（`https://api.bilibili.com/x/v2/reply`）阶段失败，未能获取到任何评论数据。

### 3.2 报错信息

```
请求 B站评论接口失败
URL: https://api.bilibili.com/x/v2/reply?type=1&oid={aid}&sort=2&pn=1&ps=20
异常类型: requests.exceptions.ConnectionError
异常信息: HTTPSConnectionPool(host='api.bilibili.com', port=443):
  Max retries exceeded with url: /x/v2/reply
  (Caused by NewConnectionError('<urllib3.connection.HTTPSConnection object at 0x...>:
  Failed to establish a new connection: [WinError 10060] 由于连接方在一段时间后没有正确答复或连接的主机没有反应，连接尝试失败。'))
```

### 3.3 原因分析

1. **网络连通性失败**：当前运行环境无法与 `api.bilibili.com` 建立 HTTPS 连接（WinError 10060 连接超时），属于网络层阻断，非接口参数或鉴权问题。
2. **可能的具体原因**：
   - 运行环境无外网访问权限或存在防火墙/代理拦截；
   - B站接口对当前出口 IP 存在访问限制（风控/地域限制）；
   - DNS 解析或 TLS 握手被中间设备阻断。
3. **非代码逻辑问题**：BV 号已确认有效，采集脚本参数配置正确，失败发生在网络请求阶段，与采集逻辑无关。

### 3.4 已尝试的排查

- 确认 BV 号格式与有效性（BV1iuXkYHEBE）；
- 确认采集脚本参数（排序=热度、数量=Top1）配置正确；
- 重试请求后仍返回相同 ConnectionError，判定为环境网络不可达。
