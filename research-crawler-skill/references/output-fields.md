# 输出字段定义与标签体系

本文件定义评论分析 CSV 的 12 个字段填写规则和标签体系。AI 分析阶段必须严格遵循。

## 12 字段定义

| 字段 | 填写规则 | 由谁填充 |
|---|---|---|
| 序号 | 从 1 开始递增 | 爬虫 |
| 平台 | Steam / B站 / TapTap / Reddit / 小红书 / 其他 | 爬虫 |
| 游戏名称 | 使用统一游戏名 | 爬虫 |
| 评论内容 | 保留原文，不改写玩家评论 | 爬虫 |
| 情绪倾向 | 正向 / 中性 / 负向 / 混合 | AI |
| 情绪关键词 | 提取 1-5 个关键词 | AI |
| 是否提及治愈 | 是 / 间接相关 / 否 | AI |
| 治愈相关度 | 1-5 分 | AI |
| 治愈感受细分 | 选择 1-3 个标签，可多选 | AI |
| 吸引游玩因素 | 选择 1-3 个标签，可多选 | AI |
| 判断依据 | 摘录最能支撑判断的短句或关键词 | AI |
| 复核调整说明 | 记录二次复核是否上调，以及上调原因 | AI |

- 前 4 个字段（序号/平台/游戏名称/评论内容）由爬虫自动填充。
- 后 8 个字段由 AI 分析填充。若用户未选择 AI 分析，这些字段留空。

## 原始评论 CSV 字段（raw/，6字段）

| 字段 | 说明 |
|---|---|
| 编号 | 从 1 开始递增 |
| 昵称 | 评论者用户名 |
| 用户ID | 评论者 mid |
| 评论内容 | 评论原文 |
| 发布时间 | YYYY-MM-DD HH:MM:SS |
| 点赞数 | 评论点赞数 |

## 治愈感受细分标签

优先使用以下标签（可多选，选 1-3 个）：

- 放松解压
- 安心平静
- 温暖陪伴
- 美术疗愈
- 音乐疗愈
- 自然疗愈
- 慢节奏休闲
- 情绪共鸣
- 社交温情
- 创造满足
- 可爱愉悦
- 非治愈/负向

## 吸引游玩因素标签

优先使用以下标签（可多选，选 1-3 个）：

- 治愈感
- 美术
- 音乐
- 玩法
- 探索
- 建造装饰
- 收集养成
- 剧情角色
- 社交
- 低压力
- 价格/口碑
- 其他
